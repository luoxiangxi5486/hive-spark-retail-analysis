# 02 · 数据存储与传输

对应 `slides/第3章-3.4项目实践.pptx` §3.4.1 与 `reports/` 实训报告05。

四个阶段：**数据集预处理与上传 HDFS → Hive 建库建表与统计 → Sqoop 导出到 MySQL → MySQL 清洗与结果导出**。

## 1. 数据集预处理与上传 HDFS

### 1.1 转码

原始 CSV 为 GBK 编码，需转为 UTF-8，否则 Hive／Spark 读取中文会乱码。

```bash
cd ~/data
iconv -f gbk -t utf8 MarketSales_edit.csv > MarketSales_transform1.csv
head -5 MarketSales_transform1.csv         # 确认中文正常显示
```

### 1.2 删除表头行

```bash
sed -i '1d' MarketSales_transform1.csv
```

> Hive 外部表不会自动跳过表头，保留表头会在统计时多出一条脏记录。

### 1.3 上传 HDFS

```bash
/usr/local/hadoop/sbin/start-all.sh

cd /usr/local/hadoop
./bin/hdfs dfs -mkdir -p /supermarket/dataset/user_log
./bin/hdfs dfs -put ~/data/MarketSales_transform1.csv /supermarket/dataset/user_log

# 校验
./bin/hdfs dfs -cat /supermarket/dataset/user_log/MarketSales_transform1.csv | head -3
```

## 2. Hive 建库建表与查询分析

### 2.1 启动

```bash
service mysql start
hive
```

### 2.2 创建数据库与外部表

```sql
create database supermarket;
use supermarket;

create external table supermarket.user_log(
    id STRING,
    itemcode STRING,
    itemname STRING,
    ficheno STRING,
    merchant_date STRING,
    amount DOUBLE,
    price DOUBLE,
    linenettotal DOUBLE,
    linenet DOUBLE,
    branchnr STRING,
    branch STRING,
    salesman STRING,
    city STRING,
    region STRING,
    latitude DOUBLE,
    longitude DOUBLE,
    clientcode STRING,
    clientname STRING,
    brandcode STRING,
    brand STRING,
    category_I STRING,
    category_II STRING,
    category_III STRING,
    startdate STRING,
    enddate STRING,
    sex STRING
)
ROW FORMAT DELIMITED FIELDS TERMINATED BY ','
STORED AS TEXTFILE
LOCATION '/supermarket/dataset/user_log';
```

> 用 `external` 是因为数据文件由 HDFS 管理，删表不删数据。

### 2.3 查询分析

```sql
-- 总数据量
select count(*) from user_log;

-- 商品一级分类
select distinct category_I from user_log;

-- 会员数量
select count(distinct ficheno) from user_log;

-- 带条件：某大类下的二级分类
select distinct category_II from user_log where category_I='FOOD';
select distinct category_II from user_log where category_I='DRINK';
```

期望：总量约 61 万条，会员约 5.2 万人。

### 2.4 创建内部临时表

Sqoop 只能导出 Hive 内部表（`/user/hive/warehouse/` 下）的数据，外部表目录不在该路径，因此需先落一份内部表。

```sql
create table supermarket.inner_user_log(
    id STRING, itemcode STRING, itemname STRING, ficheno STRING,
    merchant_date STRING, amount DOUBLE, price DOUBLE,
    linenettotal DOUBLE, linenet DOUBLE, branchnr STRING, branch STRING,
    salesman STRING, city STRING, region STRING, latitude DOUBLE,
    longitude DOUBLE, clientcode STRING, clientname STRING, brandcode STRING,
    brand STRING, category_I STRING, category_II STRING, category_III STRING,
    startdate STRING, enddate STRING, sex STRING
)
ROW FORMAT DELIMITED FIELDS TERMINATED BY ','
STORED AS TEXTFILE;

INSERT OVERWRITE TABLE supermarket.inner_user_log
select * from supermarket.user_log;
```

内部表数据位置：`/user/hive/warehouse/supermarket.db/inner_user_log`。

## 3. Sqoop 导出 Hive → MySQL

### 3.1 MySQL 侧建库建表

```bash
mysql -u root -p123456
```

```sql
create database supermarket;
use supermarket;

create table `supermarket`.`user_log` (
    `id`            varchar(100),
    `itemcode`      varchar(100),
    `itemname`      varchar(100),
    `ficheno`       varchar(100),
    `merchant_date` varchar(100),
    `amount`        varchar(20),
    `price`         varchar(20),
    `linenettotal`  varchar(20),
    `linenet`       varchar(20),
    `branchnr`      varchar(20),
    `branch`        varchar(100),
    `salesman`      varchar(100),
    `city`          varchar(100),
    `region`        varchar(100),
    `latitude`      varchar(20),
    `longitude`     varchar(20),
    `clientcode`    varchar(20),
    `clientname`    varchar(100),
    `brandcode`     varchar(20),
    `brand`         varchar(100),
    `category_I`    varchar(100),
    `category_II`   varchar(100),
    `category_III`  varchar(100),
    `startdate`     varchar(100),
    `enddate`       varchar(100),
    `sex`           varchar(20)
) engine=InnoDB default charset=utf8;
```

### 3.2 执行导出

```bash
cd /usr/local/sqoop

bin/sqoop export \
  --connect jdbc:mysql://localhost:3306/supermarket \
  --username root \
  --password 123456 \
  --table user_log \
  --export-dir '/user/hive/warehouse/supermarket.db/inner_user_log' \
  --fields-terminated-by ','
```

### 3.3 校验

```sql
mysql -u root -p123456
use supermarket;
select count(*) from user_log;
```

记录数应与 Hive 中 `user_log` 一致（约 61 万）。

## 4. MySQL 数据清洗与结果导出

后续分析只用到 **sex、category_I、category_II、city** 四列，因此只需清理这四列中的空值行。

### 4.1 先统计空值行数量

```sql
select count(*) from user_log where city='';
select count(*) from user_log where category_I='';
select count(*) from user_log where category_II='';
select count(*) from user_log where sex='';
```

### 4.2 删除空值行

```sql
delete from user_log where city='';
delete from user_log where category_I='';
delete from user_log where category_II='';
delete from user_log where sex='';
```

### 4.3 导出 CSV

`into outfile` 受 `secure_file_priv` 限制，先确认可用目录：

```sql
show variables like "secure_file_priv";
```

本环境为 `/var/lib/mysql-files/`，导出：

```sql
select * from user_log
into outfile '/var/lib/mysql-files/MarketSales_341results.csv'
fields terminated by ',' lines terminated by '\n';
```

**带表头**的导出（用 `union all` 拼一行表头）：

```sql
select * from (
    select 'id','itemcode','itemname','ficheno','merchant_date','amount','price',
           'linenettotal','linenet','branchnr','branch','salesman','city','region',
           'latitude','longitude','clientcode','clientname','brandcode','brand',
           'category_I','category_II','category_III','startdate','enddate','sex'
    union all
    select id, itemcode, itemname, ficheno, merchant_date, amount, price,
           linenettotal, linenet, branchnr, branch, salesman, city, region,
           latitude, longitude, clientcode, clientname, brandcode, brand,
           category_I, category_II, category_III, startdate, enddate, sex
    from user_log
) b
into outfile '/var/lib/mysql-files/MarketSales_341results.csv'
fields terminated by ',' lines terminated by '\n';
```

拷回数据目录并改权限：

```bash
sudo cp /var/lib/mysql-files/MarketSales_341results.csv /home/hadoop/data/
sudo chown 777 /home/hadoop/data/MarketSales_341results.csv
```

### 4.4 常见报错

| 报错 | 原因 | 处理 |
|---|---|---|
| `The MySQL server is running with the --secure-file-priv option` | 导出路径不在 `secure_file_priv` 白名单内 | 改用 `show variables` 查到的目录，再复制到目标位置 |
| `ERROR 1290 (HY000)` | 同上，本质是同一限制 | 同上 |
| 导出文件无表头 | 默认 `into outfile` 不写列名 | 用 §4.3 的 `union all` 写法 |
