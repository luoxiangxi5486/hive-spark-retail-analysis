# 01 · 环境部署

对应 `slides/第3章-3.2项目环境部署.pptx` 与 `reports/` 实训报告04。

目标：在 Ubuntu 18.04 上以 `hadoop` 普通用户完成 **Hadoop 2.7.1 伪分布式 + MySQL 5.7.16 + Hive 1.2.1 + Sqoop 1.4.6 + Spark 2.4.0** 的安装配置。

> **约定**：以下所有命令均在 `hadoop` 用户下执行，不再重复 `sudo su hadoop`。

## 1. 基础准备

### 1.1 创建用户与 SSH 免密

```bash
sudo useradd -m hadoop -s /bin/bash
sudo adduser hadoop sudo
sudo passwd hadoop
su hadoop

sudo apt-get update
sudo apt-get install -y vim
sudo apt-get install -y openssh-server
sudo /etc/init.d/ssh start

# 免密登录本机（Hadoop 伪分布式必需）
ssh-keygen -t rsa                       # 一路回车
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
ssh localhost                           # 应无需密码直接进入
```

### 1.2 安装 JDK 1.8.0_162

```bash
cd /usr/lib
sudo mkdir jvm
sudo tar -zxvf ~/jdk-8u162-linux-x64.tar.gz -C /usr/lib/jvm/
```

在 `~/.bashrc` 末尾追加：

```bash
export JAVA_HOME=/usr/lib/jvm/jdk1.8.0_162
export JRE_HOME=${JAVA_HOME}/jre
export CLASSPATH=.:${JAVA_HOME}/lib:${JRE_HOME}/lib
export PATH=${JAVA_HOME}/bin:$PATH
```

```bash
source ~/.bashrc
java -version        # 应显示 1.8.0_162
```

## 2. Hadoop 2.7.1 伪分布式

### 2.1 解压与授权

```bash
sudo tar -zxvf ~/hadoop-2.7.1.tar.gz -C /usr/local/
cd /usr/local
sudo mv ./hadoop-2.7.1/ ./hadoop
sudo chown -R hadoop ./hadoop

/usr/local/hadoop/bin/hadoop version     # 应显示 Hadoop 2.7.1
```

### 2.2 core-site.xml

`/usr/local/hadoop/etc/hadoop/core-site.xml`：

```xml
<configuration>
    <property>
        <name>hadoop.tmp.dir</name>
        <value>file:/usr/local/hadoop/tmp</value>
        <description>Abase for other temporary directories.</description>
    </property>
    <property>
        <name>fs.defaultFS</name>
        <value>hdfs://localhost:9000</value>
    </property>
</configuration>
```

### 2.3 hdfs-site.xml

`/usr/local/hadoop/etc/hadoop/hdfs-site.xml`：

```xml
<configuration>
    <property>
        <name>dfs.replication</name>
        <value>1</value>
    </property>
    <property>
        <name>dfs.namenode.name.dir</name>
        <value>file:/usr/local/hadoop/tmp/dfs/name</value>
    </property>
    <property>
        <name>dfs.datanode.data.dir</name>
        <value>file:/usr/local/hadoop/tmp/dfs/data</value>
    </property>
</configuration>
```

### 2.4 格式化并启动

```bash
cd /usr/local/hadoop
./bin/hdfs namenode -format          # 只需执行一次
sudo /etc/init.d/ssh start
./sbin/start-dfs.sh

jps                                  # 应看到 NameNode / DataNode / SecondaryNameNode
```

启动后可在浏览器访问 `http://localhost:50070` 查看 NameNode 状态。

## 3. MySQL 5.7.16

### 3.1 安装

```bash
sudo apt-get update
sudo apt-get install -y mysql-server-5.7
sudo apt install -y libmysqlclient-dev
```

### 3.2 取得初始密码

```bash
cd /etc/mysql/
sudo cat debian.cnf
```

输出形如：

```
[client]
host     = localhost
user     = debian-sys-maint
password = 74KdWFObOXKq50nK        # 本机随机生成，各机器不同
socket   = /var/run/mysqld/mysqld.sock

[mysql_upgrade]
host     = localhost
user     = debian-sys-maint
password = 74KdWFObOXKq50nK
socket   = /var/run/mysqld/mysqld.sock
```

### 3.3 建立运行目录并启动

```bash
cd /var/run
sudo mkdir mysqld
sudo chown -R mysql /var/run/mysqld
sudo chgrp -R mysql /var/run/mysqld

sudo service mysql stop
sudo usermod -d /var/lib/mysql/ mysql
sudo service mysql start
```

### 3.4 改用 root 登录

```bash
mysql -h localhost -u debian-sys-maint -p     # 输入上面查到的随机密码
```

```sql
update mysql.user set authentication_string=password('123456')
  where user='root' and host='localhost';
update mysql.user set plugin='mysql_native_password';
flush privileges;
quit;
```

```bash
sudo service mysql restart
mysql -h localhost -u root -p                 # 密码 123456
```

### 3.5 中文字符编码改为 utf8

先检查默认值：

```sql
show variables like 'character_set_%';
```

若 `character_set_database` / `character_set_server` 为 `latin1`，修改配置文件：

```bash
sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf
```

在 `[mysqld]` 下添加：

```ini
character_set_server=utf8
```

```bash
sudo service mysql restart
```

> 本环境 MySQL root 口令统一为 `123456`，Sqoop 导出与 Spark JDBC 写入均使用该口令。

## 4. Hive 1.2.1（元数据存 MySQL）

### 4.1 解压与权限

```bash
sudo tar -zxvf ~/apache-hive-1.2.1-bin.tar.gz -C /usr/local/
cd /usr/local/
sudo mv apache-hive-1.2.1-bin hive
sudo chown -R hadoop:hadoop hive
```

`~/.bashrc` 追加：

```bash
export HIVE_HOME=/usr/local/hive
export PATH=$HIVE_HOME/bin:$PATH
export HADOOP_HOME=/usr/local/hadoop
```

### 4.2 hive-site.xml

```bash
cd /usr/local/hive/conf
mv hive-default.xml.template hive-default.xml
vim hive-site.xml
```

```xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?>
<?xml-stylesheet type="text/xsl" href="configuration.xsl"?>
<configuration>
    <property>
        <name>javax.jdo.option.ConnectionURL</name>
        <value>jdbc:mysql://localhost:3306/hive?createDatabaseIfNotExist=true&amp;useSSL=false</value>
        <description>JDBC connect string for a JDBC metastore</description>
    </property>
    <property>
        <name>javax.jdo.option.ConnectionDriverName</name>
        <value>com.mysql.jdbc.Driver</value>
        <description>Driver class name for a JDBC metastore</description>
    </property>
    <property>
        <name>javax.jdo.option.ConnectionUserName</name>
        <value>hive</value>
        <description>username to use against metastore database</description>
    </property>
    <property>
        <name>javax.jdo.option.ConnectionPassword</name>
        <value>hive</value>
        <description>password to use against metastore database</description>
    </property>
</configuration>
```

> `useSSL=false` 必须显式写进连接串，否则启动 Hive 时会报 SSL 相关警告。

### 4.3 MySQL 驱动与元数据库

```bash
sudo tar -zxvf ~/mysql-connector-java-5.1.40.tar.gz
sudo cp ./mysql-connector-java-5.1.40/mysql-connector-java-5.1.40-bin.jar /usr/local/hive/lib

sudo service mysql restart
mysql -h localhost -u root -p
```

```sql
create database hive;
grant all on *.* to 'hive'@'localhost' identified by 'hive';   -- MySQL 5.7 写法
flush privileges;
```

MySQL 8.0 需改用：

```sql
create user 'hive'@'localhost' identified with mysql_native_password by 'hive';
grant all privileges on *.* to 'hive'@'localhost';
flush privileges;
```

### 4.4 启动验证

```bash
/usr/local/hadoop/sbin/start-all.sh
/usr/local/hive/bin/hive          # 出现 hive> 提示符即成功
```

```sql
hive> exit;
```

## 5. Sqoop 1.4.6

```bash
sudo tar -zxvf ~/sqoop-1.4.6.bin__hadoop-2.0.4-alpha.tar.gz -C /usr/local/
cd /usr/local
sudo mv sqoop-1.4.6.bin__hadoop-2.0.4-alpha sqoop
sudo chown -R hadoop:hadoop sqoop
```

配置 `sqoop-env.sh`：

```bash
cd sqoop/conf/
cp sqoop-env-template.sh sqoop-env.sh
vim sqoop-env.sh
```

```bash
export HADOOP_COMMON_HOME=/usr/local/hadoop
export HADOOP_MAPRED_HOME=/usr/local/hadoop
export HBASE_HOME=/usr/local/hbase
export HIVE_HOME=/usr/local/hive
```

`~/.bashrc` 追加：

```bash
export SQOOP_HOME=/usr/local/sqoop
export PATH=$PATH:$SQOOP_HOME/bin
export CLASSPATH=$CLASSPATH:$SQOOP_HOME/lib
```

放入 MySQL 驱动并测试连通：

```bash
sudo cp ~/mysql-connector-java-5.1.40-bin.jar /usr/local/sqoop/lib
sudo service mysql restart

sqoop list-databases --connect jdbc:mysql://127.0.0.1:3306/ --username root -P
# 输入口令后列出数据库列表即为连接成功
```

## 7. Python 环境（PySpark 兼容性）

系统自带 Python 3.10 与 Spark 2.4.0 不兼容，需用 Miniconda 建 Python 3.6.9 虚拟环境。

```bash
sudo apt update
sudo apt install -y wget bzip2

wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O ~/miniconda.sh
bash ~/miniconda.sh -b -p $HOME/miniconda3
$HOME/miniconda3/bin/conda init bash
source ~/.bashrc

conda create -n spark24 python=3.6.9 -y
conda activate spark24          # 提示符变为 (spark24)

cd /usr/local/spark
pip install numpy
./bin/pyspark
```

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `hdfs namenode -format` 后启动失败 | 多次格式化导致 clusterID 不一致 | 删除 `/usr/local/hadoop/tmp` 后重新格式化 |
| 启动 Hadoop 要求输入密码 | SSH 免密未生效 | 检查 `~/.ssh/authorized_keys` 权限是否为 600 |
| Hive 启动报 SSL 警告 | 连接串未显式声明 `useSSL=false` | 按 §4.2 修改 `hive-site.xml` |
| MySQL 无法 root 登录 | 未切换 `mysql_native_password` | 按 §3.4 更新 `mysql.user` |
| PySpark 报 Python 版本错误 | 系统 Python 3.10 不兼容 Spark 2.4 | 用 conda 建 3.6.9 环境，见 §7 |
| Sqoop 连不上 MySQL | 缺 JDBC 驱动 | 复制 `mysql-connector-java-5.1.40-bin.jar` 到 `sqoop/lib` |
